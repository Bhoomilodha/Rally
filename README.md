# 🏸 Rally - Local Sports & Partner Finder Platform

Rally is an immersive, premium, and futuristic sports partner finder and court reservation platform. Built with a high-fidelity glassmorphic visual language, it connects local players, schedules matches, coordinates split-payments, and uses a global context-aware AI assistant to orchestrate gameplay in real time.

---

## 🚀 Key Features

* **Command Center Dashboard**: Today's matches, upcoming bookings, real-time weather suitability, inbox notifications, weekly goals, and active friends list.
* **AI Matchmaker & Discover**: Advanced natural language query console, autocomplete search recommendations, and location radius controls.
* **Timeline Court Booking**: Step-by-step court schedule picker, equipment rentals, split-billing options with selected friends, and secure payment checkout.
* **Interactive Venue Discovery**: Map coordinate pins, real-time facility occupancy meters, active weather warnings, parking tags, and accessibility indicators.
* **Sports Passport (Profile)**: Interactive player visas showcasing level stats, level XP progress meters, Mon-Sun active calendars, skill attributes gauges, and achievement trophies cabinet.
* **Global AI Assistant**: Floating spark assistant that returns custom-tailored inline HTML recommendations for local courts, matching player cards, or personalized weekly schedules.
* **Control Settings Panel**: User-specific dashboard tabs configuring account details, notification channels, privacy parameters, theme options (Midnight/Neon/Light), and accessibility settings.

## 🛠️ Technology Stack

* **Core**: React 19 + TypeScript + Vite 8
* **Styling**: Tailwind CSS + Custom Design System Tokens
* **Animations**: Framer Motion (Hardware-accelerated transitions)
* **Icons**: Lucide React
* **Linting**: Oxlint

## 💻 Local Setup & Development

To run the application locally, follow these commands:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   *The application will boot at `http://localhost:5173/`.*

4. **Build the production bundle**:
   ```bash
   npm run build
   ```
   *Build assets will output to the `dist/` directory.*
